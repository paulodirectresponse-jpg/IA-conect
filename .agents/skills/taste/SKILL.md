# Taste — IA-conect

Use this skill before a major redesign when one or more reference websites are available.

## Goal

Extract both WHAT a reference does and WHY it works:

- visual hierarchy
- density and information rhythm
- spacing system
- typography scale
- color roles
- borders, depth and surfaces
- navigation patterns
- component grammar
- interaction feedback
- responsive decisions
- deliberate omissions

## Workflow

1. Open the reference with Playwright MCP when available.
2. Inspect desktop and mobile.
3. Record concrete visual patterns and tokens.
4. Infer the trade-offs behind those patterns.
5. Separate transferable principles from brand-specific decoration.
6. Compare the result with `DESIGN.md`.
7. Translate only the principles that improve IA-conect.
8. Never copy logos, proprietary imagery, copywriting, or distinctive branded assets.

## Required output

For every analyzed reference, produce:

- **Keep** — principles that fit IA-conect.
- **Reject** — patterns that conflict with the product.
- **Translate** — how the useful idea should look using our own components and tokens.
- **Risk** — accessibility, responsiveness, performance, or trend risks.

The goal is stronger taste, not imitation.
