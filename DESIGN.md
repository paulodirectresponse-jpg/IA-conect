# IA-conect — Design Direction

## Desired character

Premium AI studio. Technical, restrained, precise, contemporary and confident.

The product should feel closer to a professional creative tool than a generic SaaS dashboard.

## Visual principles

- Strong hierarchy with few competing accents.
- Dark theme may use deep blue-black surfaces; light theme uses cool neutral surfaces.
- Cyan/blue is the primary functional accent, not decoration everywhere.
- Use gradients only when they reinforce brand or primary action.
- Prefer subtle hairlines, controlled depth and clean spacing over heavy shadows or glass effects.
- Cards exist for grouping, not as the default wrapper for every element.
- Model media covers should be visually rich while controls stay readable.
- Dense operational screens should remain compact and scan-friendly.
- Typography should establish hierarchy before color, glow or size tricks.
- Empty states and loading states should look intentional, not like placeholders.

## Motion

- Crisp and restrained.
- Favor 150–250ms UI feedback where motion is useful.
- Exits generally faster than entrances.
- Avoid bounce-heavy or cinematic movement in the studio.
- Respect reduced motion.
- Avoid animations on interactions repeated constantly.

## Responsive behavior

- Mobile is redesigned, not merely compressed.
- Preserve primary action visibility.
- Avoid horizontal overflow except intentional media rails.
- Touch targets remain comfortable.
- Long configuration panels should preserve a clear progression and sticky/visible generation action where appropriate.

## Avoid

- Generic AI purple-blue gradient everywhere.
- Excessive glassmorphism.
- Cards inside cards inside cards.
- Arbitrary rounded rectangles for every icon.
- Decorative glows used as hierarchy.
- Low-contrast gray text.
- Too many simultaneous animation effects.
- Copying the visual identity of reference products instead of translating principles.

## Redesign rule

For a whole-site repagination, first audit and document the incumbent UI. Keep product behavior and content truth. Replace visual decisions only when the new direction is clearly stronger and consistent across the full product.
